# dbt-iris documentation

dbt-iris is the dbt adapter for InterSystems IRIS. Start with the tutorial if you want to see it
work, or the overview if you want to know how it works first.

| Page                                  | Read it when                                                           |
| ------------------------------------- | ---------------------------------------------------------------------- |
| [Overview](overview.md)               | You want to know what dbt-iris does in IRIS and why                    |
| [Tutorial](tutorial.md)               | You want to go from nothing to `dbt build` on the example project      |
| [Configuration](configuration.md)     | You need a profile setting or a model, seed or snapshot config         |
| [IRIS SQL differences](iris-sql.md)   | A model written for another warehouse fails or gives different results |
| [Troubleshooting](troubleshooting.md) | You have an error message                                              |
| [dbt Fusion (preview)](fusion.md)     | You want to know where dbt Fusion support stands                       |
| [Contributing](contributing.md)       | You are changing dbt-iris and need to run its tests                    |

The pages written for docs.getdbt.com are in [`dbt-docs-site/`](dbt-docs-site/): the
[setup page](dbt-docs-site/iris-setup.md) and the [configs page](dbt-docs-site/iris-configs.md).
What changed in each release is in the [changelog](../CHANGELOG.md).
